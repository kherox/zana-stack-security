# Référence REST interactive

La référence ci-dessous est **générée depuis le code** de la plateforme
(contrat OpenAPI, source de vérité unique, garde anti-dérive en CI) et
rendue par un visualiseur **embarqué** : aucune ressource externe n'est
chargée — la page fonctionne aussi bien en ligne que dans un réseau isolé.

Le contrat machine brut est disponible : [`openapi.json`](../api/openapi.json).

!!! note "Lecture seule"

    Cette référence décrit la surface `/api/v1` complète d'une instance.
    Les routes accessibles aux intégrateurs externes (clés d'API) sont les
    cinq routes de lecture décrites dans le
    [guide d'intégration](integration.md) : alertes, événements, incidents,
    agents et résumé agrégé — les autres routes requièrent une session
    utilisateur interne.
